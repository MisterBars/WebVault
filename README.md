# WebVault

Автономный сайт заметок для IIS: классический ASP.NET / .NET Framework, C#, HTML/CSS/JavaScript и MS SQL Express 2014. Заметки хранятся Markdown-файлами вне публичного каталога сайта.

## Статус
Планирование и проверка целевой среды. Рабочего приложения пока нет.

- [Состояние и план](docs/project_overview.md)

Последующие спецификации размещаются в docs/specifications. Документы реализации — в docs.

## Ограничения
Целевая исходная среда: Windows 7, существующий IIS/ASP.NET, SQL Express 2014, работа без интернета и установки новых системных компонентов. Точные версии Framework и браузера ещё проверяются. ASP.NET Core не используется. Access рассматривается только как будущая локальная альтернатива.

## Данные и секреты
Не добавлять реальные заметки, вложения, резервные копии, пароли и рабочие строки подключения. Репозиторий содержит исходный код и документацию, а не пользовательское хранилище.
