# WebVault

Автономный сайт Markdown-заметок для IIS: классический ASP.NET / .NET Framework, C#, HTML/CSS/JavaScript и SQL Express 2014. Личные файлы хранятся вне публичного сайта. ASP.NET Core не используется.

## Состояние
Работают аккаунты, личные хранилища, папки/файловые операции, корзина, мультивыделение/drag с прокруткой, автосохранение и CM6 с тремя режимами Markdown. Пользователь проверил основные файловые сценарии, режимы на «00 — Markdown — Навигация» и первый импорт/экспорт .md. Это не полная совместимость с Obsidian и не завершение всех негативных тестов. Delete/Ctrl+A дерева отложены как неработающие.

Новый комплект: ZIP-импорт со структурой папок, ZIP-экспорт группы/папки и обозреватель назначения. Исходники подготовлены, требуют npm install/test/build и браузерной проверки. [Инструкция и лимиты переноса](docs/note_transfer.md). Вложения пока не переносятся.

## Обновление
Публиковать только src/WebVault.Web, не корень Git, tools, docs или node_modules. На рабочий ПК переносить готовый JS; npm для запуска сайта не нужен. При изменении tools/cm6/зависимостей нужна сборка. Исходники в Git не означают обновлённый bundle. После обновления сохранить заметки и Ctrl+F5. npm test/build не заменяют браузерную проверку.

SQL-миграции — 00–07 в database/install. first_install.md перечисляет базу до 05; дополнения 06/07 читать отдельно. На существующей установке применять только неприменённые после бэкапа БД/DataRoot, не запускать установку заново наугад. ZIP-комплект SQL не меняет.

## Среда и данные
Целевая среда: Windows7/.NET Framework4.5/Firefox113, IIS и SQL Express2014 на одной машине, без интернета/новых системных установок на рабочем ПК. Сборка выполняется дома. Независимые установки автоматически не синхронизируются.

Не коммитить реальные заметки, DataRoot, вложения/бэкапы, пароли, рабочий Web.config и секреты. node_modules игнорируется; package-lock.json сохранять с соответствующим package.json. Проверенный bundle можно включать в комплект переноса. История и внешние бэкапы не стираются удалением заметки.

Интерактивные флажки/даты, свойства, редактируемые таблицы, подсказки ссылок и навигация ещё в очереди. Каждый следующий комплект обновляет профильную инструкцию и README/указатель; различать реализацию, проверку, ограничения и план.
