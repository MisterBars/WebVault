# WebVault

Автономный браузерный сайт заметок для IIS: классический ASP.NET / .NET Framework, C#, HTML/CSS/JavaScript и MS SQL Express 2014. Заметки — Markdown-файлы в личном хранилище вне публичного каталога сайта. ASP.NET Core не используется.

## Состояние

Приложение уже работает и развивается по результатам пользовательских проверок. Реализованы вход и администрирование, личные хранилища, папки, создание/переименование/перемещение, корзина с восстановлением, групповые действия, автосохранение и редактор CodeMirror 6 с исходным, динамическим и читаемым представлением Markdown. Пользователь подтвердил основные файловые сценарии и работу режимов на тесте «00 — Markdown — Навигация». Это не означает завершения всех негативных тестов или полной совместимости с Obsidian. Delete/Ctrl+A файлового дерева отмечены пользователем как неработающие и отложены.

CodeMirror поставляется исходниками и требует локальной сборки JS. Наличие исходников в Git не означает, что браузерный bundle обновлён. Последний Markdown-комплект и его ограничения: [блочный Live Preview](docs/live_preview_blocks.md).

## Установка и обновление

Публиковать только `src/WebVault.Web`, а не корень репозитория. `DataRoot`, БД и локальный `Web.config` не входят в публичный сайт. На рабочем компьютере не требуется установка npm для запуска готового сайта.

В `database/install` присутствуют миграции 00–07. Базовая инструкция первой установки пока перечисляет 00–05; дополнения 06/07 описаны отдельно в документах выше. Перед запуском SQL читать соответствующие скрипты и инструкции. На существующей установке применять только ещё не применённые миграции после бэкапа БД и DataRoot, не запускать установку заново наугад.

После обновления JS/CSS — сохранить заметки и обновить страницу через Ctrl+F5. При изменении `tools/cm6` или его зависимостей сначала заново собрать bundle по [руководству npm](docs/npm_build.md). Чисто серверные/обычные JS-изменения вне сборки не требуют npm, если инструкция комплекта не говорит иное.

## Среда и ограничения

Целевая рабочая среда — Windows 7 / .NET Framework 4.5 / Firefox 113, IIS и SQL Express 2014 на одной машине; работа без интернета и без новых системных установок на рабочем ПК. Сборку зависимостей выполняют отдельно на домашнем/разработческом компьютере. Проверка каждого нового комплекта в целевой среде всё равно необходима. Независимые установки автоматически не синхронизируются. Импорт/экспорт Markdown/ZIP пока только согласованы в плане.

## Данные и секреты

Не добавлять реальные заметки, вложения, DataRoot, бэкапы, пароли, рабочий `Web.config` и секретные строки подключения. Репозиторий содержит код и документацию, не пользовательское хранилище. Проверять необратимое удаление сначала на копиях. История и внешние бэкапы не стираются кнопкой удаления заметки.
