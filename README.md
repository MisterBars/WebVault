# WebVault

Автономный сайт Markdown-заметок для IIS: классический ASP.NET/.NET Framework, C#, HTML/CSS/JavaScript и SQL Express2014. Личные файлы вне публичного сайта, ASP.NET Core не используется.

## Состояние
Реализованы аккаунты, личные хранилища, файлы/папки, корзина, группы/drag, автосохранение, CM6 и три режима Markdown, перенос .md/ZIP и первый индекс/граф. Пользователь подтвердил основные файловые сценарии, импорт/экспорт и работу графа. Полная совместимость с Obsidian и все негативные тесты не подтверждены. Delete дерева работает по последнему отзыву; Ctrl+A ранее отмечен как ограничение.

Новый UI-комплект: граф в центральной рабочей области, иконка слева, исправленные подписи SVG; импорт/экспорт в Настройки → Общее. Исходники требуют сборки и браузерной проверки. [Изменения интерфейса](docs/workspace_layout.md). Никакие ещё согласованные редакторские функции автоматически не считаются реализованными.

## Обновление и среда
Публиковать src/WebVault.Web, не корень Git/tools/docs/node_modules. Исходники tools/cm6 требуют сборки и не означают обновлённый bundle. Сохранить заметки, перенести готовый JS, Ctrl+F5. npm test/build не заменяют браузерную проверку. Node/npm для запуска на рабочем ПК не нужны.

SQL00–07 в database/install; базовая инструкция до05, дополнения06/07 читать отдельно. На обновлении только неприменённые миграции после бэкапа БД/DataRoot. UI-комплект SQL/Web.config не меняет. Цель: Windows7/.NET Framework4.5/Firefox113, IIS/SQL Express2014 на одной машине; автономная работа, сборка дома.

Не коммитить реальные заметки/DataRoot/вложения/бэкапы, пароли и рабочий Web.config. node_modules игнорируется, lock сохранять с package.json; проверенный bundle можно переносить через Git. История/внешние бэкапы не очищаются удалением заметки. Независимые установки не синхронизируются автоматически. Каждый комплект обновляет инструкцию и README/указатель, различая реализацию/проверку/план.
