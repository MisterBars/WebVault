## Правила выполнения и отчётности

Читать GitHub самостоятельно и работать пакетами с полным точным подтверждением. При обрезании дочитать, не заменять потерянный конец догадкой. После записи проверить SHA/состав/полные diff; для удаления дополнительно ссылки/отсутствие. Пустой content не удаление. Телефонная работа не требует pull/fetch/PowerShell/сборки/браузера на ПК для продолжения. [github_transfer.md](github_transfer.md) — будущая безопасная синхронизация, не обязательный конец каждого пакета.

Код/SQL/CSS-JS/зависимости/lock/bundle/данные/секреты/рабочий Web.config/node_modules под видом docs не менять. Исходники вне docs читать адресно для контракта/проверок, не запускать P. Корневые README/CHANGELOG — документальный объём. Не reset --hard/clean/force push/автоматический stash. Untracked vendor только исторический локальный факт; не трогать/не выдавать за текущий status. Старые локальные snapshots сохраняет реестр до переноса, нового получения/чистоты не подтверждено.

Отчёт: SHA/состав/реальные переносы/удаления/добавления, проверки/ограничения/остаток, необходимость build/публикации и примерный экспертный процент нормализации. Не повышать оценку за чтение/коммит/синхронизацию автоматически, не объявлять непроведённые тесты/полный аудит.
