# Динамический просмотр блоков
Статус: исходники подготовлены. npm install/test/build и браузер не запускались. Готовый bundle не обновлён. Дома: cd tools/cm6; npm install; npm test; npm run build; затем Ctrl+F5 и перенос полученного vendor/webvault-cm6.js. Сохранить обновлённый lock. На рабочем ПК npm не нужен.
Вместо минимальных маркеров используются CM6 block replacement widgets. Вне активного блока виден отформатированный DOM, активный блок или выделенные диапазоны показывают исходник. Обычный клик раскрывает блок с курсором в начале; точное место курсора выбирается вторым кликом. Списки/таблицы/цитаты/код раскрываются целиком. Номера строк и folding относятся к исходнику. Большие документы/перестройка высот и выделение мышью через границы требуют браузерных тестов.
Чтение и live используют один markdown-it parser и один DOM renderer. HTML из исходника не исполняется; renderer создаёт разрешённые элементы через DOM/textContent, не использует innerHTML или штатный HTML renderer. Ссылки допускают http/https/mailto; изображения пока текстовые заглушки без сетевых загрузок. Нет custom highlight callback.
Поддержаны базовый Markdown, Setext, абзацы/переносы, вложенные emphasis, strike, ==mark== через markdown-it-mark, таблицы, списки/цитаты/код, сущности/escape. Задачи пока статические символы, не интерактивные чекбоксы. Frontmatter отображается сворачиваемым исходным YAML без разбора типов и редактирования свойств. Callout — визуальный заголовок/рамка для обычной цитаты, без fold-семантики. Wiki alias отображается; переход в live через Ctrl/Meta+клик, обычный клик раскрывает исходник. В чтении обычный клик открывает ссылку. Простое имя ищется в каталоге текущей заметки; путь с / — от корня. Нет глобального поиска aliases/basename, разрешения неоднозначностей и ссылок на heading/block; отсутствующий файл выдаёт ошибку, сам не создаётся.
Не реализованы сноски, %% комментарии, скрытие HTML-комментариев, math, Mermaid, Dataview, плагины, настоящий HTML, загрузка вложений. Это не полная совместимость с Obsidian и не утверждение о прохождении 00/01.
Автосохранение/серверные операции без изменений; режимы не пересоздают EditorState, открытие другой заметки по-прежнему создаёт новое состояние. Старый двухрежимный просмотр остаётся только резервом при отсутствии CM bundle; в CM три режима управляют собственными source/live/read областями. Delete/Ctrl+A файлового дерева не исправлялись по приоритету пользователя.
Тесты node покрывают парсинг и source maps, но не DOM/CM6. Проверить после сборки: 00 и 01, таблицу/списки/цитату/код из остальных групп, раскрытие целых блоков, клавиатуру/выделение/IME, source/live/read, undo после autosave, исходник после сохранения, wiki при dirty/ошибке/404, смену учётки, удаление открытой заметки, отсутствие внешних запросов от вложений, HTML/javascript-ссылки. При проблеме live перейти в source, не менять заметки вручную через SQL.
