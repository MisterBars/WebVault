## Исправление source
Source context теперь ограничивается текущей ячейкой распознанного markdown-it table-блока. Незавершённое [[ не захватывает ]] соседней ячейки; разделитель alignment не принимает completion. При вставке в таблицу внутренние pipe экранируются, вне таблицы обычный wiki остаётся без структурного backslash. Выделение подписи учитывает длину итогового текста. Проверки кода/YAML/комментариев, владельца, режима и snapshot сохранены.

Исправление предназначено для новых вставок. Уже сохранённые неэкранированные wiki внутри таблиц не переписываются автоматически: их структура неоднозначна. Для отдельной старой ссылки исправить pipe в source или заново создать её в корректной ячейке. Не выполнять массовую regexp-замену заметок. Если проблема воспроизводится вне таблицы — требуется отдельный Markdown-пример, этот комплект не объявляется универсальным ремонтом renderer.

## Меню столбца
В dynamic над заголовком появляется ⋯ при hover/focus: По умолчанию/Слева/По центру/Справа. Меняется только соответствующая ячейка строки-разделителя (---/:---/:---:/---:), число дефисов и прочие байты сохраняются. Заголовок и тело получают выравнивание через прежний renderer. Подтверждённая операция — отдельный input.table.align/isolateHistory Undo/Redo, прежнее автосохранение; повтор текущего варианта ничего не записывает.

Перед открытием меню подтверждается черновик ячейки; если из-за commit таблица перестроилась, меню открывается уже на актуальном DOM. Неподтверждённые свойства/readonly/busy/stale doc блокируют действие. Controls исключены из наружного pointerdown ячеек, события меню не запускают редактирование заголовка. Escape закрывает, стрелки/Home/End выбирают пункт, фокус/Tab доступны. В reading меню не добавляется.

Контракт: .wv-table-with-alignment, .wv-table-column-tools[data-wv-table-controls], .wv-table-align-menu[role=menu], [role=menuitemradio][aria-checked], style wv-table-align-style. Токены background-primary/modifier-border/hover, text-normal/muted, font-ui-small/interface, radius-s/m. 22px сверху отводятся локально под controls таблицы; не глобальное изменение отступов блоков. Положение/обрезание меню у краёв панели проверить в браузере.

Метки: window.__WV_TABLE_TEST='table-source-align-18c', window.__WV_LINKS_TEST='wiki-table-source-18c'. Новых зависимостей/SQL/Web.config изменений нет. TABLE-SOURCE-LINKS-01 и TABLE-ALIGN-01 — кандидаты до приёмки. Checkbox матрицы и перенос/добавление строк/столбцов остаются далее.
