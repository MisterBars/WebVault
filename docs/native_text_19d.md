# Нативный текст и код — ограниченный кандидат native-text-19d

24.10.2026. Дополняет paragraph_lines_19b.md и widget_click_19c.md. Пользователь не принял 19c: курсор должен попадать в место клика, текст не должен раскрываться целиком, маркеры раскрываются локально. Дополнительно сообщил пропуск блоков кода при движении курсора в dynamic. Не считать пропуск доказанным следствием atomicRanges: в editor он содержит свойства/свёрнутые разделы, а не обычный код.

## Первый этап
Обычные корневые текстовые абзацы и код fence/code_block не заменяются BlockWidget в dynamic. Символы текста и переводы строк остаются нативными CM, штатные клик/стрелки/выделение не проходят через revealAtPoint. Декорации оформляют StrongEmphasis/Emphasis/Strikethrough/InlineCode/Highlight; заменяются только отдельные диапазоны маркеров без newline. Видимость маркера определяется курсором в его диапазоне/на границе или пересечением выделения. Изменение видимости не dispatch selection или changes. Номера строк штатные. Код получает оформление строк; fence/info скрываются локальными заменами и раскрываются у курсора. Это не новый подсветчик языков и не полноценный редактор таблиц.

Source parser дополнен WVHighlight/WVStrike через Lezer delimiters, без новых зависимостей. Их полную совместимость с markdown-it-mark/strike и неоднозначными delimiter cases ещё проверить. Dynamic-стили не включаются в source; требование цветного ==mark== в source пока не закрывается.

## Явные ограничения
Абзацы с wiki/обычными ссылками, изображениями, HTML BR, escape или сущностями пока остаются в прежнем пути. Для них сохраняются ограничения 19b/19c: это НЕ полное исправление первого клика во всех заметках. Сложные строки не выдавать за уже перенесённые на inline. После приёмки основы отдельные этапы должны перенести эти конструкции без потери существующего поведения. Заголовки, цитаты, списки, свойства, таблицы и reading не переделываются. Обычный код перестаёт быть replacement widget, но фактическая навигация через него пока не проверена браузером. Пустые строки fence сохраняются; их скрытие целиком не входит в этап.
