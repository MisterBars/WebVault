# Первый клик — кандидат widget-click-19c

24.10.2026. Дополняет paragraph_lines_19b.md. Пользователь положительно оценил 19b, но сообщил, что первый клик по строке ставит курсор в начало. Это открытая регрессия; полная приёмка комплекта не заявлена.

BlockWidget раньше всегда dispatch anchor=block.from. Новый revealAtPoint сначала раскрывает выбранный диапазон без scrollIntoView, затем через requestMeasure/posAtCoords определяет позицию по clientX/clientY и ограничивает её диапазоном блока. У построчных абзацев это диапазон одной исходной строки. Изменение касается обычного раскрытия BlockWidget, не native-кликов уже раскрытого исходника. Ссылки и folding сохраняют прежние ветки, таблицы используют свой UI; reading не получает свободного редактирования.

Между раскрытием и измерением проверяются идентичность документа/выделения, режим, заметка, пользователь и disabled. Изменившийся контекст отменяет коррекцию. Текстовые изменения не dispatch, история текста и autosave не вызываются этим helper. При отсутствии найденной позиции остаётся начало блока. Это координаты раскрытого исходника, не точная source-map от каждого символа formatted DOM: маркеры, шрифты, переносы и изменение высоты могут влиять на попадание. Drag-selection/Shift-click/double-click не объявлены полноценно исправленными этим этапом и требуют отдельной проверки.

11 изолированных кейсов helper с View-заглушкой прошли у ассистента в Node. Браузерное попадание, CodeMirror requestMeasure, wiring editor.js, полный npm test/build и Firefox/IIS здесь не запускались. Кандидат до приёмки. Зависимости/SQL/Web.config/готовый bundle не меняются.

После pull из tools/cm6, по очереди после успеха предыдущего:

```powershell
npm test
node --test widget_click.test.mjs paragraph_preview.test.mjs markdown_br.test.mjs markdown_dom.test.mjs
npm run build
```

Обновить bundle и Ctrl+F5. Метка window.__WV_WIDGET_CLICK_TEST='widget-click-19c'. Проверить первый клик в начале/середине/конце обычной строки и сразу ввести символ; клик второй строки не раскрывает первую; длинная строка и прокрутка; форматирование и код; ссылки/folding/таблицы без регрессии; нумерация и BR сохранны; быстрые повторные клики не возвращают старую позицию; Undo/Redo/save/reopen и source/reading. Проверить также Shift-click, двойной клик и протягивание выделения, не считать их поддержанными по одному обычному клику.
