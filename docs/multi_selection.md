# Мультивыделение и групповые действия
Статус: исходники подготовлены, браузерные тесты не запускались. Обновить файлы сайта, Ctrl+F5; SQL и CodeMirror build не нужны.
Дерево: Ctrl/Meta-клик добавляет/убирает без открытия, Shift-клик диапазон видимых строк, обычный клик оставляет один элемент и открывает как прежде. ПКМ внутри выбранной группы сохраняет выбор, вне группы выбирает один. Групповое меню показывает только команды с multi:true; новые плагины должны явно объявлять этот признак и обрабатывать c.items. При выбранной папке её выбранные потомки исключаются из снимка операций. Счётчик показывает число выбранных строк, число реальных операций может быть меньше. Скрытые после сворачивания выбранные строки остаются в выборе; фильтр сбрасывает выбор. Escape снимает выбор; Ctrl+A только в дереве выбирает видимые строки, Delete перемещает выбранные в корзину без подтверждения. F2 остаётся только для одиночного выбора с фокусом строки.
Перетаскивание любого выбранного элемента переносит группу. Автопрокрутка только #files в зоне 42px у верхнего/нижнего края, до 600px/с, останавливается на выходе/drop/dragend/blur. Автораскрытие свёрнутой папки пока не добавлено. Перемещение в себя/потомка и группа с одинаковыми конечными именами отклоняются до операций; существующие назначения не перезаписываются сервером. В том же каталоге — пропуск. Индикатор группы текстовый в счётчике/drag data, отдельной drag-картинки нет.
Операции идут последовательно, не атомарно; максимум 100 корневых элементов в дереве, успехи снимаются с выбора, ошибки остаются. При session/uncertain дальнейшая группа останавливается. После частичного успеха и ошибки обновления списка итог может потребовать ручного refresh; не повторять группу вслепую. Автосохранение текущей заметки перед операциями, редактор заблокирован на время группы. Внешние изменения на диске по-прежнему вне общей транзакции.
Корзина: компактная таблица, Ctrl/Shift выбор, общие restore/purge/clear. ПКМ групповой, просмотр по двойному клику/Enter, смена пути через отдельную команду или после одиночного отказа restore. Восстановление родителя всё ещё не создаёт отсутствующие папки. Ошибки и pending-состояния учитываются; очистка — только снимок показанных ID. История и бэкапы не удаляются. Быстрое восстановление относится ко всей последней успешно удалённой группе.
Проверка: Ctrl/Shift/ПКМ на выбранном и невыбранном; папка+ребёнок; ошибка одного файла; совпадение имён/существующее назначение; drag выделенной группы; прокрутка с неподвижным курсором у края и отмена за пределами; 100+ элементов; удаление открытой заметки; restore/purge группы и отмена; смена пользователя/истечение сессии; сохранность ввода и Ctrl+Z; клавиатура/Firefox113. Код не следует считать проверенным до этих тестов.
