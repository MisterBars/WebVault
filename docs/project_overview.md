# WebVault — состояние проекта

## Подтверждено пользователем дома
ASP.NET/SQL, создание администратора и обычного пользователя, ограничения административного доступа. После комплекта 36991b1 пользователь сообщил «всё работает»: переименование и два режима удаления считаем проверенными в основном сценарии. Полный набор негативных/конкурентных тестов и рабочий Framework 4.5 отдельно не подтверждены.

## Новый комплект — код подготовлен, не проверен в IIS
- PasswordChangeHandler и api/auth/change_password.ashx: собственный пароль с проверкой текущего, повтором нового, транзакционным отзывом всех сессий.
- account.html: форма для обеих ролей; кнопка «Учётная запись» в общей навигации.
- ui.js: очистка состояния при 401, выход при уже истёкшей сессии.
- password_change.md: запуск и проверки.
Новая миграция и конфигурация не нужны; существующая схема 00–04.

## Ближайший шаг
Получить код, Ctrl+F5, проверить смену на тестовой личной учётке, старый/новый пароль и отзыв ранее открытых сессий. Административный пароль тоже можно менять только свой и с текущим паролем; не тестировать восстановление через удаление администратора. После проверки переходить к личным хранилищам и редактору, сразу связанным с навигацией.

## Существующие решения
Админ — управление пользователями/правами, личные заметки — отдельная обычная учётка. Начальная настройка показывается только если разрешена сервером и пользователей нет. Мягкое удаление оставляет запись/логин; полное после мягкого удаляет учётку/сессии и освобождает логин. Файловый модуль ещё отсутствует; purge необходимо доработать при его внедрении.

## Документы
first_install.md, deployment.md — установка/генерация ключа/порядок 00–04. user_management.md — переименование/удаления. password_change.md — новая смена пароля; она заменяет старые отметки «смена не реализована» в документах ранних этапов. Схема auth неизменна.

## Осталось
Файловые хранилища, редактор, поиск, настройки/темы, расширения, самостоятельная регистрация, роли, восстановление/сброс пароля, полноценное журналирование и бэкап. AuthHandler/WebApi предстоит объединить. Режим Windows 7/Framework 4.5/Firefox 113.0 требует проверки на работе, системные компоненты там не скачивать. Разработка D:\project\WebVault, IIS/SQL на одной машине, WebVaultPool, Integrated Security. Изолированные установки не синхронизируются; администратор ОС вне модели приватности. Возврат подробного локального health-ответа и выключение setup явно не подтверждены — проверить при развёртывании.
