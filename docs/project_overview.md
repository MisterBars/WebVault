# WebVault — состояние проекта

## Подтверждено пользователем дома
Основные сценарии ASP.NET/SQL, пользователей/авторизации/переименования/двух удалений, смены пароля и первых файловых заметок приняты в общем виде. Obsidian-подобный личный раздел после ba83fbd пользователь оценил положительно. Это не подтверждение всех негативных/конкурентных тестов или рабочего Framework 4.5.

## Новый комплект — единый дизайн, требует проверки
app.css использует obsidian-tokens.css и оформление workspace. ui.js строит общий каркас для auth/users/account/index: header, ribbon, меню разделов по роли, прокручиваемый main и status-bar. Формы/события/API сохранены. Рабочая область заметок исключена из повторного построения. disabled кнопок восстанавливается к исходному состоянию. Описание и тесты — application_design.md. Обновление только файлов, без SQL/Web.config.

## Важные решения
Админ для управления, отдельная обычная учётка для заметок. Новые функции сразу связывать с интерфейсом. CSS-переменные и структура близки к Obsidian, но тема Minimal не заявлена автоматически совместимой; CodeMirror/Live Preview отсутствуют. Все ресурсы локальны, настройки тем в будущем индивидуальны.

## Текущее файловое ядро
05_user_vaults.sql, storage.UserVaults, DataRoot/vaults и history. .md только в корне, ручное сохранение, UTF-8, ограничения первого этапа до 256 KiB/500 файлов. Версия SHA-256, конфликт не перезаписывается, история пока без UI/метаданных имени. Одновременных внешних писателей Obsidian/синхронизаторов не использовать. Полное удаление владельца хранилища блокируется FK/user_has_dependencies, требуется согласованная очистка; мягкое работает.

## Далее
Проверить все страницы после Ctrl+F5. Затем дерево папок и операции заметок/корзина/история; очистка владельца; безопасный Markdown-просмотр/настоящий редактор и ссылки; автосохранение; персональные настройки и темы; расширения. Самостоятельная регистрация, роли, восстановление пароля, полные логи и резервирование пока в плане. AuthHandler/WebApi требуют рефакторинга.

## Документы и среда
application_design.md — новая оболочка, theme_compatibility.md — CSS-контракт заметок; file_vault.md — установка 05/DataRoot поверх first_install.md/deployment.md до 04; password_change.md и user_management.md — учётки. Разработка D:\project\WebVault, цель Windows 7/Framework 4.5/Firefox 113.0, IIS и SQL Express 2014 вместе, WebVaultPool/Integrated Security. На рабочем ПК ничего из системных компонентов не скачивать. Независимые установки не синхронизируются; администратор ОС вне модели приватности.
