## Что нужно выяснить перед кодом
1. Версия .NET Framework, используемый компилятор и пул IIS.
2. Версия браузера на целевом ПК.
3. Экземпляр SQL Server, способ аутентификации, доступность создания отдельной БД. Пароли не публиковать.
4. Каталог данных и учётная запись пула с доступом к нему.
5. Разработка ведётся на том же рабочем ПК или на отдельном ПК с последующим переносом.
