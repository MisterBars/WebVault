# WebVault — состояние проекта

## Подтверждено пользователем дома
ASP.NET/SQL, администратор/пользователи, ограничения, переименование/удаление, смена пароля в основном сценарии. После файлового этапа пользователь сообщил «всё отлично», основной цикл заметок считаем принятым, полный набор проверок изоляции/конфликтов/сбоев и рабочий Framework 4.5 отдельно не подтверждены.

## Новое требование
Личный раздел максимально приблизить к Obsidian по компоновке и CSS-контракту, чтобы уменьшить привыкание и объём адаптации тем. В MyVault выбран Minimal; настройки тем должны в будущем оставаться индивидуальными. Административный интерфейс можно оставить простым.

## Новый комплект, не проверен в браузере
obsidian-tokens.css — наши стили со стандартными именами переменных. workspace.css — рабочая область без карточного UI. workspace.html/workspace.js — ribbon, сворачиваемый список, фильтр имени, одна вкладка, заголовок, текстовая область, строка состояния, Ctrl+S/Ctrl+O. Существующий API/БД/Markdown-файлы не меняются. Подробности и честная матрица совместимости в theme_compatibility.md. Это не CodeMirror/Live Preview, не полный порт Minimal и не готовый менеджер тем.

## Обновление
Получить код без потери локальных изменений, Ctrl+F5, проверить уже работающие создание/чтение/запись и конфликт двух вкладок. Новый SQL/Web.config не требуется; нужна ранее настроенная версия 05 и DataRoot. Не переносить единственную копию MyVault.

## Существующие ограничения
Только .md в корне, ручное сохранение, UTF-8, до 256 KiB и 500 файлов списка. Нет папок, предпросмотра, автосохранения и исполнения плагинов. История создаётся, но ещё без интерфейса/метаданных имени. Полное удаление пользователя с хранилищем блокируется FK/user_has_dependencies; требуется согласованная очистка каталога/истории/реестра. Мягкое удаление работает. Внешние писатели Obsidian/синхронизаторы одновременно не использовать.

## Дальше
Дерево папок, операции заметок/корзина/история, очистка владельца, безопасный Markdown-просмотр/редактор и ссылки, автосохранение, персональные настройки и темы, расширения. Конкретные библиотеки проверять под Firefox 113 и автономную поставку, без установок на рабочем ПК. Документировать CSS-контракт, не подменять совместимость фиктивными классами. AuthHandler/WebApi по-прежнему нуждаются в рефакторинге.

## Среда и документы
D:\project\WebVault, цель Windows 7/.NET Framework 4.5/Firefox 113.0, IIS + SQL Express 2014 на одной машине, WebVaultPool, Integrated Security. Данные отдельно, DataRoot. first_install/deployment до 04 дополняются file_vault.md с 05; theme_compatibility.md — оформление. Пароль — password_change.md; пользователи — user_management.md. Самостоятельная регистрация/роли/восстановление пароля/бэкап/полные логи пока в плане. Изолированные установки не синхронизируются; администратор ОС вне модели приватности. Проверить выключение setup/очистку ключа и отсутствие подробной health-диагностики при развёртывании.
