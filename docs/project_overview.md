## Безопасность
health.ashx теперь проверяет административную сессию и локальность; гостю 401, обычной учётке 403. Проверка не только в меню. До создания админа диагностика IIS/SSMS/setup_status, не health. При 401 приватные панели скрываются; черновик только в памяти вкладки, после входа той же учёткой продолжается, при другом входе/явном выходе очищается. Нет обещания автоматической блокировки по таймеру, межвкладочной синхронизации или шифрования памяти.
