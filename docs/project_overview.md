# WebVault — состояние проекта

## Подтверждено пользователем дома
ASP.NET/SQL HTTP 200; исправлена привязка пула на WebVaultPool; применён 02_auth.sql; создание администратора и авторизация работают после включения AdminSetupEnabled; обычный пользователь создаётся; ограничения административного доступа работают. Полный набор негативных тестов и рабочий Framework 4.5 не подтверждены.

## Решения по интерфейсу
Админ занимается пользователями/правами; для личных заметок используется отдельная обычная учётка. Новые API сопровождать связанным интерфейсом и кнопками. Завершённую первоначальную настройку скрывать.

## Новый комплект — требует проверки
- 03_user_lifecycle.sql: DeletedUtc для мягкого удаления.
- AdminUsersHandler: создание/список без удалённых и удаление обычных пользователей с отзывом сессий.
- setup_status: серверное условие показа первоначальной настройки.
- assets/css/app.css и assets/js/ui.js: общий интерфейс и навигация.
- auth/users/index обновлены; workspace.html — обозначенный каркас личного раздела.
- ui_and_users.md: порядок обновления и проверки.

## Ближайшие действия
Резервная копия БД; получить код; применить 03; проверить маршрутизацию после входа, скрытие setup, навигацию и удаление. Проверить локальное выключение настройки/очистку ключа. Потом смена своего пароля и личные хранилища.

## Документация
first_install.md — генерация ключа, создание администратора и повторная установка. deployment.md — базовое развёртывание. Новое дополнение и миграция описаны в ui_and_users.md. Для новой установки после 02 дополнительно выполнить 03 перед использованием обновлённого интерфейса пользователей. users.md/API_OVERVIEW.md описывают исходный этап; изменения удаления/статуса/интерфейса уточняются в ui_and_users.md.

## Среда и ограничения
D:\project\WebVault, разработка дома/на ноутбуке, цель Windows 7/.NET Framework 4.5/Firefox 113.0, IIS и SQL Express 2014 на одной машине, Integrated Security, WebVaultPool. Системные компоненты на рабочем ПК не устанавливать.
Не реализованы: самостоятельная регистрация, смена/сброс пароля, роли и восстановление удалённых, файловые хранилища и редактор, поиск, настройки/темы, расширения, полноценные логи и бэкап/восстановление. Изолированные установки не синхронизируются. Временное подробное health-исключение локально должно быть убрано; подтверждения пока нет. AuthHandler/WebApi предстоит объединить при рефакторинге. Администратор ОС с доступом к диску вне модели приватности.
