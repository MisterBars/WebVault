- Согласование оставшихся ссылок/статусов после удаления пары; первый адресный пакет не весь репозиторий. Известные оговорки в handoff/месячном файле/предметных руководствах ещё согласовать, не повторяя архивную реконструкцию или удаление.
- Только ещё не перенесённая история/существенное других источников, без восстановления удалённого архива ради исчерпанного условия хранения.
- Общий аудит Markdown/якорей/путей/команд/статусов/полноты и определение автоматической проверки. Обрезанный/incomplete_results поиск не доказывает отсутствие ссылок.

Поведение остальных handlers/HTTP-входы вне api и оставшийся предметный DOM/CSS/тематический аудит открыты. Minimal-аудит не loader/менеджер; Firefox113/ресурсы/лицензии/opaque-eink сохраняются.
