## Остаток и условие удаления

- Только ещё уникальное архива/прочих источников; полная сохранность архива и общая ранняя история не завершены.
- Происхождение неверной checksum и входящие ссылки; подтверждённое несовпадение не называть отсутствием вычисления хеша.
- Общий аудит Markdown/якорей/путей/команд/статусов/полноты и определение автоматической проверки. Обрезанный/incomplete_results поиск не доказывает отсутствие ссылок.
- Построчная связь требований обоих ТЗ/backlog с реализацией/подключением/доказательствами; готовые матрицы, карта9+9 приёмки и карта18 API не составляются заново. Поведение остальных handlers/HTTP-входы вне api и оставшийся предметный DOM/CSS/тематический аудит открыты. Minimal-аудит не loader/менеджер; Firefox113/ресурсы/лицензии/opaque-eink сохраняются.
