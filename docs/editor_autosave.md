# Автосохранение и базовый Markdown
Статус: подготовлено, браузер/IIS не проверены. SQL и Web.config не меняются.
editor_features.js подключается локально модулем account_features.js; внешних библиотек/CDN нет. Это временная точка подключения до выделения общего загрузчика модулей.
Сохранение: через 1000 мс после ввода, последовательными запросами через существующий app.run/saveNote и серверную проверку версии. Во время фонового запроса ввод не блокируется; новые изменения сохраняются следующим запросом. Ошибка останавливает автоповторы до явного сохранения. Текст остаётся в textarea, присваивания value при сохранении нет. Кнопочные переходы при dirty сначала сохраняют текст; в это время поле readOnly. При неудаче действие не повторяется. Во время занятой операции переход нужно повторить. Ctrl+S и кнопка повторного сохранения доступны. Перечитывание при конфликте намеренно заблокировано до ручного копирования текста и перезагрузки страницы; отдельный диалог разрешения конфликтов ещё нужен. Черновики на диске браузера не создаются, сохранение на закрытии не гарантируется; предупреждение beforeunload остаётся.
Markdown: отдельный просмотр, не Live Preview и не полный CommonMark. Заголовки ATX, простые списки без вложенности, цитаты, fenced code, разделители, inline code, strong/em, внешние http/https/mailto ссылки. HTML отображается как текст через DOM textContent; innerHTML не применяется. Картинки, таблицы, wiki-ссылки, плагины и Dataview пока не реализованы. Файл остаётся исходным Markdown.
Вкладки, split view, F2 и файловый undo этим комплектом не меняются.
Проверка: ввод и пауза; ввод во время запроса; Ctrl+Z после сохранения; открытие другой заметки при dirty; rename/move; потеря сети и повтор; конфликт из второго профиля; logout/login другой учёткой без старого preview; HTML и javascript-ссылки в просмотре. Сначала тестировать на копиях заметок.
