## Подготовленные изменения
- Меню тела использует propertyLinkChoices: тот же поиск по словам в пути, сортировка по совпадению имени/пути и близости папки, максимум 30 результатов. Собственная повторная фильтрация CodeMirror отключена, результат пересчитывается при изменении запроса.
- Название без расширения и полный путь выводятся отдельными строками; палитра, отступы, радиусы и подсветка соответствуют picker свойств. DOM остаётся штатным CM, это не перенос native input controller. Footer-инструкция picker свойств здесь пока не добавлена.
- После выбора выделяется существующая либо стандартная подпись. Ввод заменяет только её; путь и закрывающие скобки сохраняются. Вставка остаётся отдельным шагом Undo.
- Проверки каталога, владельца, заметки, режима и кода сохранены; обычные completion-источники не заменяются override.
