# Развёртывание WebVault

Основная инструкция: [first_install.md](first_install.md), включает генерацию ключа и создание администратора. Нужны отдельный IIS-пул WebVaultPool и локальный Web.config. Публиковать только src/WebVault.Web, не корень Git-репозитория. IIS и SQL предполагаются на одной машине, подключение Integrated Security.

## SQL-порядок новой установки
00_database.sql -> 01_grant_apppool_access.sql -> 02_auth.sql -> 03_user_lifecycle.sql -> 04_user_management.sql из database/install.
На существующей установке выполнить только новые миграции после резервной копии. 03 добавляет DeletedUtc; 04 выдаёт приложению DELETE на auth.Users для явного полного удаления, без db_owner. Ни один из этих установочных скриптов сам пользователей не удаляет.

## Страницы
index.html — диагностика; auth.html — вход и условная первоначальная настройка; users.html — администратор; workspace.html — каркас личного раздела.
Навигация общая. После существующего администратора setup скрыт; ключ всё равно удалить, настройку выключить.
