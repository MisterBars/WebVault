# Развёртывание WebVault

Полная пошаговая инструкция для новой установки, включая генерацию ключа и создание первого администратора: [first_install.md](first_install.md).

## Порядок SQL-установки
1. Создать в IIS пул WebVaultPool: CLR v4.0, Integrated, ApplicationPoolIdentity.
2. Выполнить database/install/00_database.sql.
3. Выполнить database/install/01_grant_apppool_access.sql.
4. Выполнить database/install/02_auth.sql.

Имена БД/пула должны совпадать с конфигурацией; SQL и IIS предполагаются на одной машине. Пул без db_owner. Сайту явно назначить WebVaultPool.

## Каталоги
IIS обслуживает только src/WebVault.Web. Пример: D:\project\WebVault\src\WebVault.Web. Репозиторий целиком и его .git не публиковать. Каталог данных заметок будет находиться отдельно; сейчас файловое API ещё не создано.

## Конфигурация
При новой установке копировать Web.config.example в Web.config; при обновлении существующий Web.config сохранять и дополнять вручную. Секреты и Web.config не входят в Git. Настройка AdminSetupEnabled по умолчанию false; ключ после инициализации удалить.

## Проверка
- index.html — диагностический каркас, ASP.NET/SQL.
- auth.html — первоначальная настройка и вход/выход.
- users.html — следующий подготовленный модуль администратора, требует тестирования.

Локальный тест: http://127.0.0.1:8085. Привязка 127.0.0.1 без внешнего доступа. Первоначальная настройка допускается только локально. Работа в локальной сети — отдельный этап с HTTPS.
