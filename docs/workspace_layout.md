# Граф в рабочей области и раздел «Общее»

[README](../README.md) · [Указатель](index.md) · [npm](npm_build.md). Статус: исходники подготовлены, сборка/DOM/IIS/браузер не проверены. Эти указания заменяют старое размещение графа/кнопок в note_graph.md и note_transfer.md; индекс, перенос и их лимиты не меняются.

## Обновление
Новых npm-зависимостей/SQL/Web.config нет. При уже установленных зависимостях из tools/cm6: npm test, затем при успехе npm run build, новый webvault-cm6.js, Ctrl+F5. Если зависимостей нет — npm install дома по общей инструкции.

## Рабочая область
Граф теперь section в центральном main вместо dialog. Кнопка — SVG-иконка на левой ribbon. Повторное нажатие или К заметке возвращает прежний документ; файл/узел открывает заметку в текущей области. При этом текст и состояние редактора не выгружаются. Это переключение представлений, не система вкладок. Уход останавливает simulation, закрывает графические элементы и отменяет следующие шаги индексации. Уже выполняющийся запрос может завершиться, результат проверяется по поколению/пользователю перед показом.

SVG подписей получает stroke:none и font-weight:400, без обводки от общего svg-стиля иконок. Иконки не меняются. Координаты drag/zoom переводятся через матрицу SVG для изменяемого размера центральной области.

## Настройки
При обычном открытии настроек первым выбирается Общее, Учётная запись остаётся отдельным разделом. В Общем — импорт .md/ZIP, экспорт открытой .md, экспорт папки ZIP с обозревателем папок. Перед запуском операции настройки закрываются и открывается соответствующее окно переноса либо скачивается файл. Из файловой панели большие кнопки переноса удалены; ПКМ сохраняет контекстные команды. При обязательной смене пароля доступна только Учётная запись, general скрыт; административная/гостевая учётка и отсутствие vault не разрешают перенос.

Временная интеграция переключений — обёртка экспортированного A.openNote и наблюдение видимости notesPane, не полноценный Workspace Obsidian API. Приватные старые маршруты приложения могут требовать дальнейшей унификации. Раздел Общее появляется при загрузке CM bundle, не является fallback-возможностью textarea без bundle.

## Проверка
Граф → назад; граф → файл дерева/узел; все три режима заметки после возврата; несохранённый текст/ошибка сохранения; закрытие во время индексации; обычные/светлые темы и подписи без обводки; изменение ширины окна и drag; settings General/Account/клавиатура; все три операции переноса и ПКМ; временный пароль/forced change; logout/login другой учёткой без старого графа/папок. Существующие node-тесты не покрывают этот UI.
