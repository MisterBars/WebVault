## Цель и область

Описанный контракт EDITOR-GUTTER-01: в source/dynamic существующая колонка CM с номерами и штатными стрелками folding визуально привязывается к левому краю общей .markdown-source-view с отступом 8px. В reading номера не добавляются. Тело остаётся центрированным; Markdown/ranges, высоты/реальные пустые строки и история не меняются. Это не реализация folding отрисованных блоков.

Сохранено ограниченное ручное подтверждение 22.10.2026; ранний статус «локальный кандидат» относится к состоянию до него, не к нынешнему общему отрицательному статусу. Эта редактура сопоставляет существующее руководство с theme_contract.md и backlog, не перечитывает весь JS и не выполняет новую CM/DOM/Firefox/IIS-регрессию.

## Реализация

source_gutter_view.js подключает ViewPlugin и класс wv-window-gutters через EditorView.editorAttributes. Чтение геометрии и запись transform разделены requestMeasure. ResizeObserver следит за редактором/доступной областью/gutter; resize/scroll и обновления CM запрашивают измерение с общим ключом. Destroy снимает наблюдателей/события и очищает собственный inline-token.

Меняется только transform:translateX(var(--wv-source-gutter-shift,0px)) существующего .cm-gutters. Его место в потоке/зарезервированная ширина и начало текста не пересчитываются; номера не клонируются, source maps не меняются. Уже применённый transform учитывается, повторные замеры не должны накапливать сдвиг. При невозможной ширине используется естественное положение. Независимые transform/масштабирование темы требуют проверки; совместимость любой темы не заявлена.

## Контракт темы и диагностика

- .cm-editor.wv-window-gutters .cm-gutters; style id wv-source-gutter-style, штатные классы/цвета CM сохранены.
- --wv-gutter-inset на .markdown-source-view: CSS px, по умолчанию 8.
- --wv-source-gutter-shift на .cm-gutters: runtime-значение, не личная настройка. Transform принадлежит расширению; тема не должна независимо перезаписывать его без адаптации.
- window.__WV_GUTTER_TEST='gutter-left-10'; WebVaultGutter.status() выводит геометрию, не текст. Метка не версия релиза или результат проверки.
- WebVaultGutter.setEnabled(false) временно возвращает естественное положение, true включает обратно. Это диагностика текущего EditorView, без изменения заметки/сохраняемого предпочтения; после нового EditorState/открытия используется default.

## План проверки

На копии заметки проверить source/dynamic у края окна, центрирование тела, режимы, resize/сворачивание дерева, прокрутку, многозначные номера и клики штатного folding. В reading новых номеров нет. После ввода проверить Ctrl+Z/Redo, положение календаря/свойств. При дефекте сохранить status и скриншот одного сценария; setEnabled(false) использовать только для сравнения. Это план, не новый прогон.

Для функционального изменения: адресные проверки затронутой геометрии/интеграции → test:all → build после успеха → отдельная публикация → браузер по npm_build.md. Docs-only не требует сборки, install или публикации. Общие правила истории — changelog/README.md, не прежний режим CommitAccepted; README не дневник приёмок.
