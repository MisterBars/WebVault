# Положение исходной нумерации — gutter-left-10

[Контракт тем](theme_contract.md) · [Changelog](../CHANGELOG.md) · [Задачи](next_steps.md).

## Цель и область
Локальный кандидат по EDITOR-GUTTER-01. В source/dynamic существующая колонка CM (номера и штатные стрелки folding) визуально привязывается к левому краю общей области .markdown-source-view с отступом 8px. В reading номера не добавляются. Текстовая колонка остаётся центрированной; содержимое, диапазоны Markdown, высоты/пустые строки и история не меняются. Это не реализация folding отрисованных блоков.

## Реализация
source_gutter_view.js подключает ViewPlugin и class wv-window-gutters через EditorView.editorAttributes. Чтение геометрии и запись transform разделены через requestMeasure. ResizeObserver следит за редактором, доступной областью и gutter; события resize/scroll и обновления CM запрашивают измерение с общим ключом. Destroy отключает наблюдателей/события и очищает собственный inline-token.

Меняется только transform:translateX(var(--wv-source-gutter-shift,0px)) у существующего .cm-gutters; его место в потоке остаётся прежним, поэтому ширина/начало текста не пересчитываются. Номера не клонируются и source maps не меняются. Модель учитывает уже применённый transform, чтобы повторные замеры не накапливали сдвиг. При невозможной ширине применяется естественное положение. Кастомные transform/масштабирование темы требуют отдельной проверки: полной совместимости любой темы не заявлено.

## Контракт темы и диагностика
- Реальные точки: .cm-editor.wv-window-gutters .cm-gutters; style id wv-source-gutter-style. Существующие классы и цвета CM сохранены.
- --wv-gutter-inset на .markdown-source-view: настраиваемый отступ от левого края в CSS px, по умолчанию 8.
- --wv-source-gutter-shift на самом .cm-gutters: runtime-значение, не пользовательская настройка. Собственный transform gutter принадлежит расширению; тема не должна независимо перезаписывать его без адаптации.
- window.__WV_GUTTER_TEST='gutter-left-10'. window.WebVaultGutter.status() выводит только геометрию, не текст заметки.
- window.WebVaultGutter.setEnabled(false) временно возвращает естественное положение для сравнения; true включает обратно. Это диагностическое переключение текущего EditorView, не сохраняемая настройка. После нового EditorState/открытия заметки включается значение по умолчанию.

## Одна приёмка
Проверить source/dynamic слева у окна, сохранность центрирования тела, переключения режимов, resize/сворачивание дерева, прокрутку, новые многозначные номера и клики штатного folding. В reading нет новых номеров. После обычного ввода Ctrl+Z/Redo работают, календарь/свойства не переместились. При проблеме прислать status и скриншот одним сообщением; временное setEnabled(false) не меняет заметку.

Новых npm-зависимостей нет. Предыдущие приёмки и задачи сохранены. После успешной проверки запись в changelog создаётся режимом CommitAccepted, README не дополняется дневником.
