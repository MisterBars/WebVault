# Согласованные следующие задачи

Статус на 21 октября 2026: требования из пользовательских проверок, НЕ реализация этим документом. [README](../README.md) · [Указатель](index.md).

## Подтверждённые проверки

Пользователь подтвердил основные сценарии создания/открытия, корзины, выделения и перетаскивания; режимы исходного кода/динамического просмотра/чтения работают на тесте «00 — Markdown — Навигация». Delete и Ctrl+A файлового дерева отмечены как неработающие и по просьбе пользователя пока не приоритет. Полная совместимость Markdown не подтверждена.

## Ближайшие файловые изменения

- Импорт одного/нескольких .md и ZIP в выбранную папку, без молчаливой перезаписи. Для конфликтов — пропуск или другое имя. Проверки путей архива, числа файлов и распакованного размера; только личное хранилище.
- Экспорт одной заметки в .md, группы/папки в ZIP со структурой. Сначала сохранить открытый изменённый документ; при ошибке не выдавать старую версию за новую. Исходный Markdown, без преобразования в HTML. Не включать корзину, историю, служебные файлы/настройки и секреты. Это перенос копий, не синхронизация.
- Убрать постоянную кнопку быстрого восстановления из основного окна. Счётчик Корзина(N) обновлять по фактическим записям после trash/restore/purge/clear; папка с содержимым — одна запись. Сейчас сообщение о последней группе устаревает.
- Новая заметка: учитывать все совпадающие базовые имена в папке назначения и предлагать следующий числовой суффикс; при максимальном N — N+1. Серверная защита от гонки/перезаписи обязательна.
- Будущая пользовательская настройка папки для новых заметок; интерфейс настройки ещё не добавлен.

## Редактор и Markdown

- Настоящие переключаемые checkbox-контролы: пустая рамка / контрастная галочка, не статическое emoji. В таблице исходник ☐/☑, в списке [ ]/[x]. Клик мышью переключает отметку без раскрытия; исходный маркер раскрывается, когда в его позицию приходит текстовый курсор. Обычные флажки доступны и в чтении, свободный текст в чтении не редактируется. Код/экранированные примеры не превращать в контролы.
- Дата/время текущего включения справа, сохраняются вместе с заметкой; снять — убрать, поставить снова — новое время. UTC хранение, локальный показ, будущая настройка формата/видимости. Это не аудит переключений и не дата YAML-свойства enabled. Служебную запись спроектировать так, чтобы не ломать стандартные задачи и перенос исходника.
- Списки: не раскрывать весь список. Исходная разметка строки только возле маркера/текстового курсора, остальные строки отформатированы.
- Таблицы в динамическом режиме редактируются в ячейках, не превращаются целиком в Markdown. Общий undo/autosave, безопасное обновление исходника, переходы Tab/Shift+Tab с учётом открытого автодополнения.
- Выделение CodeMirror и нативного DOM привязать к теме; фон и текст различимы, не сплошное белое.
- Callout icons: info — значок информации, другие типы — соответствующие локальные значки; нейтральный fallback. Не различать типы только цветом.
- Подсказки после [[ по заметкам во вложенных папках: фильтр, стрелки, Tab/Enter принять, Escape закрыть, путь при одинаковых именах, не дублировать ]].
- Панель YAML-свойств по типам: редактируемая в dynamic, только чтение в read, исходный YAML в source. Не переписывать без нужды остальные свойства/кавычки/порядок; сложные неподдержанные значения без потерь доступны в source.

## Навигация и будущие вкладки

Обычный клик и переход по ссылке открывают в текущей вкладке; созданная заметка сразу активна там же. Добавить Назад/Вперёд с историей успешных открытий на сессию, сохранением перед уходом, обрезанием forward-ветки после нового перехода и очисткой при смене пользователя. Ошибки открытия не записывать. «Открыть в новой вкладке» — позже вместе с моделью нескольких документов; затем split view/две заметки рядом.
