## Изменение
В src/WebVault.Web/assets/css/workspace.css после существующих правил добавлен блок, ограниченный #notesPane. Общий контейнер .markdown-source-view получает overflow-y:scroll и overflow-x:auto. Контейнер колонки получает height:auto, min-height:100%, display:block. CM имеет автоматическую высоту, его scroller и reading pane — overflow:visible без ограничения max-height. Вертикальная полоса находится справа у области заметки, не внутри колонки шириной 700px. Верхний заголовок страницы и дерево файлов не включаются в прокрутку заметки; inline title, свойства и тело прокручиваются вместе.

Сохранены проверенные значения и !important для переопределения старой раскладки и встроенных стилей. Старое содержимое CSS не переформатировано. editor.js, Markdown renderer, исходные пустые строки, исправленные отступы/номера, bundle и зависимости не меняются.
