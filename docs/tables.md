## Объём первого комплекта
Таблица в dynamic остаётся отрисованной при попадании CM selection в её диапазон. Клик по тексту ячейки или Enter/F2 на сфокусированной ячейке включает textarea только этой ячейки. Остальные ячейки не раскрываются. В редакторе ячейки — её Markdown, включая структурное экранирование pipe; это не второй источник данных.

Tab/Shift+Tab подтверждают и переходят по ячейкам, Enter — ниже в том же столбце, Escape отменяет черновик, Ctrl+S подтверждает и запускает прежнее сохранение. На границе таблицы фокус возвращается редактору, новые строки автоматически пока не создаются. Shift+Enter и вставка многострочного/TSV текста отклоняются без молчаливого склеивания. Длинный однострочный Markdown переносится визуально в textarea.

Запись меняет только диапазон содержимого выбранной ячейки, не форматирует всю таблицу/заметку. Unescaped pipe экранируется; существующие escaped pipe сохраняются. Проверяются форма таблицы, число ячеек, alignment, лимит заметки и ожидаемые doc/user/path/режим/доступ. Некорректные/ragged таблицы отображаются, но редактируются через source, причина в title. Лимит редактора: 50 столбцов и 200 строк данных. Source остаётся source, reading не получает редактора текста.

Черновик блокирует общую историю, внутри textarea остаётся native undo. Подтверждённая ячейка — отдельный input.table/isolateHistory шаг, прежнее автосохранение. Перед переходом/сменой режима/сворачиванием вызывается подтверждение; pointerdown снаружи и blur также пытаются подтвердить. При отказе действие блокируется, черновик остаётся. При изменении ячейки перед кликом по ссылке рекомендуется сначала Enter/Ctrl+S: перестройка таблицы может перевести первый клик в фокус ячейки. Несколько одновременно открытых черновиков не поддерживаются.

/table и /таблица на отдельной строке source/dynamic предлагают создать 2 столбца × 2 строки данных плюс заголовок. Enter/Tab/мышь применяют completion, Escape закрывает без замены текста. В dynamic открывается первая ячейка; в source остаётся курсор в Markdown. Команда не применяется в коде/YAML/списках/цитатах, проверяет сессию и режим.
