## Новый кандидат
Любой корневой list-блок возвращает массив inline-строк (включая пустой), а не null из-за сложного элемента. Поэтому существующий editor.decorate больше не заменяет такой список целиком. Строки маркеров определяются по list_item_open.map markdown-it; пустые строки и продолжения остаются обычным CM-текстом. Код/форматирование внутри пункта больше не отключают остальные строки списка.

Маркер, wiki, checkbox и timestamp имеют независимые диапазоны. Курсор раскрывает пересечённую часть, не весь список. В задаче обычная bullet скрыта, отображается настоящий input[type=checkbox] с тематическим круглым видом. Обычный клик wiki переходит, Alt+клик раскрывает её.

Переключение задач [ ]/[x] и ☐/☑ в списках работает через одну input.task транзакцию с isolateHistory. Вместе с флажком хранится полный UTC ISO с миллисекундами в конце первой строки задачи: ` <!--wv-task:2026-10-23T17:39:00.123Z-->`. В dynamic/reading показывается локальная дата/время справа; title содержит UTC. Снятие удаляет связанную отметку, повторное включение записывает новую. Ручное изменение исходника не создаёт автоматического аудита/времени. Старые выполненные задачи без timestamp не получают вымышленной даты.

Reading использует те же task parser/контрол и защищённую CM-транзакцию, не делает тело свободно редактируемым. Callback проверяет текущие doc/user/path, доступность истории, busy/readonly/черновики, режим и подключённый видимый DOM. Просроченный контрол ничего не меняет. Некорректные/дублированные служебные отметки блокируют переключение до исправления исходника. При выборе полного текста metadata доступна как исходник, данные не прячутся навсегда.

Границы: bold/em/code и другие сложные inline-фрагменты в dynamic пока остаются обычным исходным текстом, но не вызывают цельный fallback списка. Wiki внутри inline-параграфа с code/link/image/escape/скрытым комментарием может остаться исходником локально. Вложенные block-контейнеры, списки внутри цитат, отдельные matrix-символы вне списков и полноценное оформление всех continuation-строк требуют дальнейшей работы. Полный LIST-INLINE-01 и TASKS-UI/TIME до пользовательской проверки не закрываются.

Контракт: .wv-task-checkbox, .wv-task-time, .wv-task-item; style wv-task-style; text-muted/interactive-accent/font-ui-smaller. Маркер window.__WV_LIST_INLINE_TEST='list-inline-17b'. Зависимости/SQL/Web.config не меняются.
