## Изменение
MD-MARK-SOURCE-01: общий noteAppearance подключает отдельный слой mark-декораций для AST-узла WVHighlight. В source весь диапазон ==…== получает тематический фон, включая видимые ограничители. Слой только Decoration.mark: не скрывает текст, не создаёт виджеты, не отправляет selection/changes, не переписывает Markdown. Используется существующий source parser, а не regexp по всем символам: inline/fenced/indented code и frontmatter не должны становиться выделением. Неподдержанные или незавершённые конструкции не красятся принудительно.

Слой подключён к CodeMirror в обоих редакторских режимах; в dynamic прежние nativeText-декорации по-прежнему управляют скрытием маркеров, reading использует прежний DOM renderer. Это не изменение логики курсора/заголовков/folding и не исправление всех оставшихся fallback-конструкций.

Чтобы новый непрозрачный фон не закрывал штатное выделение в source, его диапазоны вырезаются из этого слоя при непустом selection. Обычный курсор фон не убирает. Это не отдельное исправление фоновых слоёв nativeText в dynamic или всех тем.

Контракт: .wv-source-mark, EditorView.baseTheme из mark_highlight.js; background --text-highlight-bg с fallback #7b682d, color inherit. Обновление ViewPlugin по документу, выделению, viewport и транзакциям parser; без запросов к серверу. Метка window.__WV_SOURCE_MARK_TEST='source-mark-19g'.
