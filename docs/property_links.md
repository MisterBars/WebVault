# Выбор заметки в свойствах — property-links-14

[Wiki-ссылки документа](wiki_links.md) · [Панель свойств](properties_panel.md) · [Контракт темы](theme_contract.md).

## Поведение
В списковых свойствах и текстовых input/textarea ввод [[ открывает выбор заметки из того же личного каталога wiki-links-13. Путь и подпись хранятся в обычной Wiki-строке; второй индекс/серверный ID не создаётся. Выберите файл стрелками/Enter/Tab/мышью: вставится root-qualified ссылка, её подпись будет выделена для замены. Выбор ещё не записывает значение. Измените подпись и подтвердите Enter; Ctrl+S/обычная семантика подтверждения поля также сохранены.

У спискового значения после подтверждения — ссылка с крестиком, а не овальный обычный элемент. В текстовом поле хранится редактируемая строка, тип не превращается молча в список/особый Link. Prefix/suffix скалярного текста не удаляются. В textarea после выбора Enter внутри ссылки подтверждает поле; вне ссылки обычный перенос сохраняется. Подпись однострочная, без закрывающего разделителя ]]. До изменения других полей/режима завершить черновик: долгоживущее хранение всех native-draft пока не реализовано.

Без [[ обычные подсказки значений тегов/алиасов/списков работают как прежде. В Wiki-режиме они отключаются, чтобы не было двух popup. Закрытие одного контроллера не удаляет aria-controls другого. Новое меню размещено fixed в body; имена и пути выводятся через textContent. Числа/флажки/даты не получают этот picker, их календарь/валидация не меняются.

В форме Добавить свойство picker доступен для text/list начального значения. Выбор только заполняет форму; запись происходит через Добавить/штатное подтверждение формы. При смене типа controller уничтожается и восстанавливает исходные атрибуты.

## Защиты и совместимость
Provider использует wikiLinks.catalog, проверяет пользователя/путь/режим/документ/readonly и актуальность каталога. Старое async меню/переименование не должно вставлять выбор в другую заметку. Выбор для старого snapshot отклоняется; Ctrl+Space в адресной части обновляет каталог. Alias-часть не используется как новый поисковый адрес. Неполная новая Wiki-строка не коммитится; Escape закрывает меню, повторный Escape отменяет Wiki-черновик поля. Неизменённое старое значение допускается без новой валидации, чтобы не ломать legacy literal [[. Код/escape в plain metadata не объявляются Markdown-языком; для буквального [[ используйте escape/исходник.

В YAML меняется только выбранное значение через прежний propertyChange/CM/Undo/autosave; остальные поля/комментарии не сериализуются. Несколько Wiki в скалярном тексте сохраняются как текст, не превращаются в один anchor. В списке ссылочное отображение требует отдельной полной Wiki-строки. parseWholePropertyWiki допускает одиночную ] внутри подписи и не принимает два отдельных Wiki за одну ссылку. #/^ подсказки и inline-списки/checkbox остаются отдельными задачами.
