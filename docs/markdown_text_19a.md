## Изменение
MD-BR-01: в общем parser dynamic/reading добавлено узкое inline-правило для <br>, <br/>, <br /> без атрибутов, без учёта регистра. Создаётся существующий hardbreak token, DOM renderer создаёт BR через createElement. html:false сохранён, innerHTML и произвольный HTML не включаются. Код, escape и сущности не должны превращаться в перенос.

Один следующий LF/CRLF с необязательными пробелами перед ним поглощается при разборе, чтобы пример «Перенос через HTML:<br>» с переводом строки не создавал два BR. Два явных <br> создают два переноса. Исходная заметка не переписывается; maps вычисляются по прежнему тексту. Softbreak и другие hardbreak не меняются.
