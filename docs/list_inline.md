## Кандидат LIST-INLINE-01, частичный объём
В dynamic простые Markdown-списки с одним физическим пунктом на строку больше не заменяются цельным block-widget. Текст остаётся обычным редактируемым CM-текстом. Каждый маркер и каждая wiki-ссылка имеют собственную inline replacement-декорацию. Курсор/выделение раскрывают только пересекаемый диапазон; клик маркера раскрывает его, обычный клик wiki открывает заметку прежним защищённым переходом, Alt+клик раскрывает ссылку. Подпись выводится через textContent. Отступ исходника сохраняется, строковые номера штатные. Ненумерованный маркер показывает •, нумерованный сохраняет записанный номер.

Основа — уже разобранные блоки markdown-it, не поиск списков по всему тексту regexp. Дополнительно проверяются допустимые токены, строки и число wiki-ссылок. Source и reading не меняются. Свёрнутые разделы не получают скрытых inline-декораций. Ничего не записывается ради визуализации; редактирование/undo/автосохранение остаются штатными.

Границы этапа: задачи [ ]/[x] и ☐/☑, многострочные/разреженные пункты, форматирование bold/em/code, Markdown-ссылки, escapes/entities/скрытые комментарии и вложенные блоки пока остаются на старом block-пути. При неподдерживаемом содержимом fallback применяется к целому соответствующему списку, данные не преобразуются. Обычная вложенность маркеров поддерживается при простых строках. TASKS-UI/TIME и полный LIST-INLINE-01 этим НЕ закрываются. Следующий этап расширяет допустимую inline-разметку и добавляет checkbox вместе с UTC timestamp, а не статический символ под видом работающего checkbox.

Контракт: .wv-list-inline-marker, a.wv-list-inline-link[data-wv-note], style wv-list-inline-style; text-muted/accent, interactive-accent. window.__WV_LIST_INLINE_TEST='list-inline-17a'.

## Чек-лист сайта
1. window.__WV_LIST_INLINE_TEST возвращает list-inline-17a.
2. В dynamic простой список - первый / - второй: клик и печать в тексте не раскрывают маркеры/соседние строки.
3. Клик в маркер/курсор стрелками раскрывает только его; выход возвращает •. Проверить нумерованный и вложенный простой список.
4. Строка - текст [[/Путь.md|Своя подпись]] хвост: текст редактируется отдельно, обычный клик переходит, Alt+клик/курсор раскрывает только ссылку. Новое [[ меню и выделение подписи работают.
5. Выделение через несколько строк, Undo/Redo, Enter/Backspace/Tab, номера строк/прокрутка, folding заголовка, source/reading и сохранение/открытие.
6. Списки задач, код/жирный текст и сложные пункты сохраняют прежнее поведение; свойства с удалением/календарём не регрессируют.
