## Объём TABLE-TASKS-01
В прямоугольной Markdown-таблице одна задача в начале ячейки: ☐/☑ или [ ]/[x]/[X], после неё допустима подпись/Markdown. Это покрывает матрицу с тремя независимыми checkbox в одной строке: каждому соответствует собственный диапазон ячейки, не общий timestamp строки. Несколько независимых checkbox внутри одной ячейки и символы посреди текста пока не превращаются в контролы. Код, escapes, wiki-подпись и Markdown-ссылка не считаются задачей по наличию символа внутри.

При переключении меняются только символ и служебный suffix выбранной ячейки ` <!--wv-task:UTC-ISO-с-миллисекундами-->`. Сохраняются соседние ячейки/комментарии, ширина таблицы, alignment, пробелы, тело и YAML. Снятие удаляет только свою отметку, повторное включение создаёт новую; старый ☑ без даты не получает вымышленного времени до нового включения. Ручное изменение source не является аудитом и автоматически время не создаёт.

В dynamic/reading это настоящий input[type=checkbox] на общем контроллере задач. Событие click не включает редактор ячейки. Полный UTC хранится в Markdown; локальные дата/время компактно показываются под checkbox, title содержит UTC. Время в списках остаётся справа. Source сохраняет доступ к символам и комментариям. Изменение флажка/времени — одна input.task/isolateHistory транзакция и один Undo/Redo; прежнее автосохранение. Текст reading не становится редактируемым.

Callback проверяет текущий doc/user/path/режим/права/readonly/busy/черновики/видимый DOM и совпадение всего исходного текста таблицы с текущим документом. Некорректные/дублированные timestamps отключают контрол до исправления source. При открытом черновике ячейки pointerdown по checkbox блокируется ДО наружного auto-commit таблицы: сначала Enter/Ctrl+S либо Escape, чтобы первый клик не открывал вместо checkbox другую ячейку. Неподтверждённые свойства также блокируют изменение через общий history policy.

parseDocument сопоставляет td/th inline tokens с исходными ячейками через table model. В таблице удаляется ошибочная списковая task-аннотация, если первая ячейка похожа на список. Неоднозначные/ragged/слишком большие таблицы остаются на прежнем отображении без нового интерактивного checkbox, а не переписываются. Общий task UI получил необязательный callback вычисления changes; defaults списков сохранены.

Контракт: input.wv-task-checkbox[data-wv-table-task], .wv-task-time.wv-table-task-time; style wv-table-task-style; прежние тематические checkbox/шрифтовые токены. aria-label содержит координаты ячейки. Маркер window.__WV_TABLE_TASKS_TEST='table-tasks-18d'; marker таблиц остаётся table-source-align-18c. Зависимости/SQL/Web.config не меняются.
