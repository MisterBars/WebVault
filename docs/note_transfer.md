## Обновление
Сохранить заметки, бэкап DataRoot, получить код. Дома из tools/cm6: npm install (новая зависимость JSZip 3.10.1), npm test, при успехе npm run build. Сохранить обновлённый package-lock.json, не коммитить node_modules. Перенести готовый webvault-cm6.js и комплект сайта; Ctrl+F5. SQL/Web.config и серверные маршруты не меняются: требуется ранее установленный NoteTransferHandler/transfer.ashx. Сборка не доказывает работу в Firefox113.

## Папка назначения
Импорт .md/ZIP из панели или ПКМ открывает текущую папку. Обозреватель показывает вложенные папки, В корень, На уровень выше и Выбрать эту папку. Последняя кнопка переносит путь в поле назначения. Простое открытие папки в обозревателе не меняет выбранное назначение. Ручной ввод сохранён. Вызов из ПКМ больше не блокируется внутренней проверкой app.isBusy.

## Импорт
Выбрать несколько .md либо один ZIP, нажать Проверить файлы, проверить назначение и режим конфликта, затем Импортировать проверенное. При ZIP сначала проверяются структура/пути/ограничения, затем ограниченно распаковываются заметки и проверяется UTF-8 до записи. Создаются допустимые каталоги под выбранным назначением; абсолютные пути/../обратные слеши/зарезервированные имена/дубликаты отклоняются. Скрытые служебные записи и не-.md не импортируются, их число показывается. Отдельные вложения пока не переносятся. Для одинаковых имён — skip либо свободное Name (N).md, без перезаписи. Ссылки в тексте не переписываются; для тестового набора предпочтительна пустая папка.

ZIP: только одиночный обычный ZIP, STORE/DEFLATE, UTF-8 имена; шифрование, ZIP64, многотомность и symlink не поддерживаются. Проверяются центральные и локальные заголовки, исходные имена до автоматической очистки JSZip, CRC/фактический размер заметок при распаковке. Лимиты: ZIP до 20 MiB, заявленный распакованный объём всех записей до 20 MiB, до 500 записей/100 .md; заметка до 256 KiB и 131072 UTF-16 code units. Устаревшие кодировки имён/нестандартные ZIP могут быть отклонены. JSZip не извлекает файлы напрямую на диск. Ограничения браузерного preflight дополняют, а не заменяют серверные проверки каждого пути/файла/сессии.

Пакет не атомарен: папки и успешные файлы остаются после ошибки. Неопределённая/сетевая/серверная ошибка останавливает следующие отправки; после потери ответа проверить дерево перед повтором с переименованием. CRC не является доказательством доверенности содержимого.

## Экспорт
Одиночная заметка — прежний .md. ПКМ выбранной группы или папки → Экспортировать ZIP. Панель Экспорт текущей папки ZIP включает её вложенные заметки; корень — всё личное дерево в лимитах. Папка+выбранный ребёнок не дублируются. В архиве пути от корня vault, не относительно выбранной папки: например Tests/00.md. Служебные каталоги, история, корзина и вложения не включаются. Пустые видимые папки сохраняются. ZIP формируется локально с STORE без CDN. При ошибке чтения/превышении лимита архив не предлагается к скачиванию как полный.

Перед экспортом открытый изменённый документ сохраняется, редактирование временно блокируется. До 500 элементов дерева/100 заметок/20 MiB данных; каждый файл читает защищённый серверный маршрут. Открытая заметка проверяется по версии. Единого атомарного снимка всего vault нет: другие сессии могут менять файлы между чтениями. Экспорт — копия, не синхронизация; браузер отвечает за запись скачанного файла.

## Проверка
Node-тесты добавлены для путей, ZIP-структуры/CRC, кириллицы, совпадений, traversal и ограниченного распакованного потока. Они не запускались здесь и не покрывают DOM/IIS. Вручную проверить обозреватель, импорт 00–07 ZIP с вложенными/пустыми папками, skip/rename, групповой экспорт и повторный импорт, байтовую сохранность BOM/CRLF, служебные файлы, испорченный/слишком большой/опасный ZIP, потерю сети и смену учётки. Интерактивные флажки/другие редакторские задачи в этот комплект не входят.
