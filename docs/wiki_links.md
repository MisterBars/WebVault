Нативный текст/код/обычные заголовки не возвращать к BlockWidget ради ссылок; резервное отображение links/BR/images и точный первый клик требуют отдельной регрессии.

## Выбор заметки в теле

После [[ в source/dynamic доступен выбор личной заметки по имени/пути: стрелки/Enter/Tab/мышь, Escape закрывает. Источник добавлен через languageData, не override всех completion; обычные HTML-подсказки не заменяются. При открытом completion Tab подтверждает выбор, иначе передаётся остальному keyboard pipeline.

inCode сверяет синтаксическое дерево и исключает FencedCode/CodeBlock/InlineCode/CodeText/WVFrontmatter и узлы Comment; если дерево недоступно, подсказка не открывается. Wiki-контекст исключает escaped [[, embed ![[ и переход через физическую строку. Дополнительный inHiddenComment проверяет незакрытые %%/HTML comments в разобранном префиксе. Эти локальные guards не являются полной реализацией MD-COMMENTS-01 для отображения/folding/индекса.

Меню использует propertyLinkChoices: слова запроса должны находиться в пути, сравнение без регистра с ё→е, декодирование запроса при возможности и необязательный начальный /. Ранжирование: точное имя, начало имени, начало пути, остальные совпадения; затем близость папки и путь. До 30 результатов. Повторная фильтрация CM отключена (filter:false), запрос пересчитывается при изменении. Имя без .md и полный путь выводятся отдельными строками; footer-инструкция native picker сюда не переносилась.

## Путь и подпись

Выбор хранится как [[/Folder/Note.md|Подпись]]. Начальный / — корень личного vault, не серверная ФС. Источник пути — авторизованный каталог, не ID массива/графа. %, #, [ и ] в имени кодируются; путь не меняется в произвольный absolute/UNC/device адрес.

При замене адресата сохраняется существующая подпись; без неё обычно используется имя файла без .md. Если имя содержит неподходящие разделители, стандартная подпись не угадывается. Подпись однострочная, без ]]. Закрывающие ]] не дублируются. После выбора выделяется подпись: новый ввод меняет её, не путь/скобки/окружающий текст. Вставка — одна input.complete транзакция с isolateHistory.of('full'), отдельная от следующего ввода подписи.

Текущий источник подсказок использует sourceWikiContext/sourceWikiInsertion также для source-таблиц: контекст ограничивается текущей ячейкой, delimiter-строка исключена, pipe вставки экранируется. Это не массовое исправление неоднозначных старых заметок. Полный контракт таблиц — tables.md; propertyLinkDraft/native поля не получают автоматически table escaping.

Перед вставкой повторно проверяются canWrite, userId, путь, режим (не reading), актуальность snapshot, текущий [[...]] диапазон и контекст кода. Устаревшее/прерванное меню не должно вставлять выбор в другую заметку или сессию. Итоговый текст ограничен 131072 UTF-16 единицами в этой ветке; это клиентский guard, не разрешение обойти серверный лимит.

## Каталог и безопасность

createLinkCatalog строит каталог через protected GET api/notes/vault.ashx?action=list&folder=..., рекурсивно по папкам; не читает тексты/не строит граф. По умолчанию максимум 300 заметок и 300 посещённых папок, включая корень; превышение — ошибка, не молчаливый неполный каталог. Посещённые папки и дубли путей различаются без регистра.

Для стандартного вызова экземпляр разделяется через WeakMap по объекту приложения. Требуется личный пользователь, не администратор/ограниченный временный вход, и инициализированное хранилище. Cache/pending/generation защищают запросы; invalidate очищает кэш и делает старый snapshot неактуальным. Обычный ввод/save не означает перечитывание всех путей на каждую клавишу. Ctrl+Space в адресной части — явное обновление. Create/move/rename/trash/restore/import и смена пользователя должны согласованно инвалидировать каталог; проверка всех событий интеграции остаётся частью регрессии приложения.

WebVaultLinks.status()/refreshCatalog() — описанная диагностика каталога без текста заметок; конкретное подключение глобального объекта сверять с загруженным приложением. В самом каталоге status возвращает cached/noteCount/pending/generation. Серверные auth/CSRF/DataRoot проверки обязательны независимо от UI/кэша.

validNotePath допускает относительный .md и отклоняет начальный /, backslash, control, недопустимые символы, пустые компоненты, . и ... CanonicalWikiTarget добавляет корневой / и кодирование разделителей только после проверки.

## Переходы и resolver

Обычный клик отрисованной wiki в dynamic переходит, Alt+клик оставляет путь к редактированию; конкретный диапазон зависит от нативного/резервного контекста. В reading — обычный переход. Существующий app-переход должен сохранять текущий документ и блокироваться незавершёнными native свойствами/формами; чтение адресата — по protected API. Ссылка не даёт доступа в обход владельца.

Markdown renderer сохраняет подпись через текстовые DOM-узлы/textContent, не innerHTML. Wiki [[target|text]] и обычная Markdown-ссылка [text](path.md) не одна грамматика; эта консолидация не расширяет автоматически поддержанные Markdown URL.

Resolver для корневого пути ищет точное совпадение без регистра, без basename fallback. Старые короткие ссылки не переписываются: относительный/корневой кандидат, затем разрешённые suffix/basename правила с ambiguous при нескольких целях. После rename/move строгая старая ссылка становится missing, не открывает другой одноимённый файл. Автоматическое обновление входящих ссылок — LINKS-RENAME-01. Префикс / с внешними инструментами проверять отдельно; тождество Obsidian не обещано.

Resolver может возвращать fragment, но это не готовый picker/прокрутка к heading/block. Текущий wikiContext отклоняет # в адресном запросе; нельзя считать наличие fragment реализацией LINKS-FRAGMENTS-01. Полный объём выбора заголовков/неоднозначности/Undo и дальнейших file#heading/^block — [backlog](next_steps.md#ссылки-и-адресация). Старое поведение открытия заметки без позиционирования не объявляется готовым переходом к фрагменту.

## DOM/CSS и диагностика

Штатные CM .cm-tooltip-autocomplete, .cm-completionLabel/.cm-completionDetail, li[aria-selected=true] и собственный .wv-wiki-option; style id wv-wiki-completion-style. Текущий стиль использует background-primary, background-modifier-border/active-hover/box-shadow, text-normal/muted, font-ui-small/smaller, --wv-ui-font/font-interface и radius-m/s, fixed ограничения ширины меню и перенос длинного пути. Фиктивные Obsidian-классы не добавляются, совместимость всех тем не гарантируется.

В сверенном wiki_completion.js installWikiCompletionStyle устанавливает window.__WV_LINKS_TEST='wiki-table-source-18c'. Старые ожидания wiki-links-13/wiki-links-15a не текущий контракт метки. Метка — исполненная ветка JS, не версия релиза, не результат теста и не доказательство актуальности bundle.

## Воспроизводимые проверки

Все сценарии — план регрессии, не отчёт об успешном запуске. Для функционального изменения из D:\project\WebVault\tools\cm6:

```powershell
& {
    Set-Location D:\project\WebVault\tools\cm6
    node --test wiki_link_model.test.mjs link_catalog.test.mjs wiki_completion.test.mjs wiki_caption.test.mjs property_link_model.test.mjs table_source_completion.test.mjs
    if ($LASTEXITCODE -ne 0) { throw 'Targeted link tests failed; stop' }
    npm run test:all
    if ($LASTEXITCODE -ne 0) { throw 'Full suite failed; do not build' }
    npm run build
    if ($LASTEXITCODE -ne 0) { throw 'Build failed; do not publish' }
}
```

После отдельной публикации bundle/Ctrl+F5 на безопасной копии:
1. Source/dynamic: [[, две строки имени/пути, поиск по словам, стрелки/Tab/Enter/мышь/Escape, обычные HTML completion не сломаны.
2. Существующая/стандартная подпись выделяется; ввод меняет только её. Одна пара ]], соседний текст не затронут, Undo/Redo и save/reopen сохраняют выбор.
3. Подпись в абзаце/заголовке/списке/цитате dynamic/reading; таблицы отдельно. Конкретный дефект фиксировать по Markdown/режиму, не массово переписывать данные.
4. Одноимённые файлы выбираются по точному пути; strict missing не basename. Native picker свойств/value-подсказки/календарь и Tab редактора не регрессируют.
5. Code/YAML/escape/embed/comments, readonly/busy/draft/forced password, смена режима/заметки/пользователя, старый async snapshot, ошибка/лимит каталога и Ctrl+Space.
6. Сохранение перед переходом, блокировка незавершённой формы, обычный/Alt-клик и клавиатурный фокус; наличие #/^ не выдаётся за готовый fragment-переход.
