# Переключатель режимов
Подготовлены исходники; сборка и браузер не проверены. После обновления: cd tools/cm6; npm run build; Ctrl+F5. При отсутствии зависимостей сначала npm install дома. Готовый bundle этим коммитом не обновляется.
Три позиции: исходный код / динамический просмотр / просмотр. Активная — иконка и подпись; остальные — иконка, title и aria-label. Подложка перемещается за 220 мс; prefers-reduced-motion отключает анимацию. Клавиши стрелок и Home/End, Tab через активную позицию. Подпись обрезается на узкой панели, полное имя доступно через title/aria-label.
Старый markdownToggle скрыт, используется как временный мост к существующему просмотру. Отдельная кнопка CM удалена. Выбранный режим редактирования сохраняется при загрузке следующей заметки в текущем окне, но не после reload. Переключение само не присваивает текст документа и не пересоздаёт историю; общий старый обработчик кнопок может сначала сохранить dirty-заметку. При отсутствующем модуле чтения переключение не применяется.
Это изменение UI, не расширение Live Preview. Существующие ограничения Markdown остаются; корзина, восстановление, очистка и полное удаление в этот коммит не включены. Проверить три позиции, загрузку следующей заметки в source/read, Ctrl+Z, dirty/ошибку сохранения, узкую панель, темы, клавиатуру, масштаб и reduced motion.
