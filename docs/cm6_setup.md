## Файлы первоначального комплекта

file_tree.js открывает созданную заметку после сохранения предыдущей; при неудачном открытии созданный файл остаётся в дереве. Подтверждение имени теперь Enter, Escape отменяет; blur не отправляет имя. Полноценных вкладок ещё нет. ПКМ удаляет файл/папку в скрытую .wv-trash внутри личного vault. JSON хранит исходный путь и ID payload; отсутствие payload означает незавершённую операцию. UI восстановления и очистки пока нет. История заметок не удаляется. Корень/скрытые служебные пути недоступны операции. Сервер сверяет метаданные дерева со stat, держит блокировки пользователя/хранилища, отказывает reparse points, дереву более 2000 элементов/50 MiB или слишком длинным путям. Метаданные — не хеш содержимого; внешние файловые изменения администратором ОС не синхронизируются. Потеря ответа после move — uncertain: не повторять вслепую, обновить дерево и сверить корзину по errorId. Открытый документ при uncertain закрывается после предварительного сохранения. Файловая система и SQL не образуют общей транзакции.

## Границы первой реализации

CodeMirror basicSetup + Markdown parser, undo/redo, базовые оформления заголовков/strong/em/code. Разметка скрывается вне активного верхнеуровневого блока, внутри блока виден исходник; выделенные диапазоны раскрываются. Это начальный Live Preview, не Obsidian-совместимость: таблицы-виджеты, свойства, callouts, wiki-ссылки, сноски, комментарии, формулы, диаграммы пока не реализованы. Чтение остаётся старым упрощённым просмотром. Новый редактор адаптирован к текущему textarea API; при открытии другого документа создаётся новое EditorState, сохранение историю не сбрасывает. Это временный мост до общей модели документов/вкладок.
