## Исправление metadata
Изолированный тест воспроизвёл причину: удаление префикса ☑ с пробелом оставляло комментарий без ведущего пробела, тогда как прежний replace искал stamp.raw вместе с пробелом. Новый stripTaskStampTokens вызывается до обработки префикса. Удаляет только подтверждённый marker текущей задачи из последовательности text-токенов, в том числе разбитый между несколькими токенами. Не мутирует исходные tokens, не удаляет код, прочие комментарии и invalid metadata. Исправление общее для renderer задач списка и ячеек.

Source, сохранённые UTC и вычисление локального времени не меняются. После обновления уже включённые checkbox должны показать только контрол/подпись/дату, без необходимости переключать их заново. В source и редакторе Markdown ячейки комментарий по-прежнему доступен как данные, это не глобальное CSS-скрытие комментариев.

## TABLE-DELETE-01
В dynamic под корректно разобранной таблицей появляется кнопка «Удалить таблицу» при hover/focus. Открывает тематический HTML dialog с размером таблицы, предупреждением об удалении содержимого и Undo, кнопками Удалить/Отмена; начальный фокус на Отмена. Escape/Отмена не создают транзакцию удаления. Reading не получает destructive control.

Перед открытием завершается черновик ячейки. Если commit перестроил документ, пользователь получает сообщение и нажимает кнопку уже на актуальном DOM повторно, чтобы не удалять таблицу по устаревшему диапазону. При применении повторно проверяются ожидаемый doc, canWrite/canStart (учётка/путь/режим/busy/readonly/черновики) и исходный текст таблицы. Dialog body находится в top layer и не запускает редактор ячейки. Если native dialog недоступен, удаления без подтверждения нет.

Удаляются только исходные строки выбранной таблицы и один её завершающий перевод строки. Соседние разделительные пустые строки и остальное содержимое не нормализуются/не сериализуются. Отдельная input.table.delete/isolateHistory транзакция и общий autosave. Undo восстанавливает таблицу вместе с alignment/ссылками/checkbox/UTC, Redo повторяет удаление; история не переживает повторную загрузку, как прежде. Таблица без соседнего текста может оставить пустую заметку. Сложные/ragged таблицы, которые модель не разрешает редактировать, удалять через source.

Кнопка добавлена рядом с существующим подключением table controls; alignment и его menu не заменяются. Контракт: .wv-table-delete-bar[data-wv-table-controls], dialog.wv-table-delete-dialog, .wv-table-delete-actions, style wv-table-delete-style; background-primary/modifier-border, text-normal/muted/error, radius-s/m, font-ui-small/interface. Маркер window.__WV_TABLE_DELETE_TEST='table-delete-18e' появляется при отрисовке редактируемой таблицы. Остальные runtime-маркеры сохраняются.
