# Компактные исходники сносок — кандидат 20f

25.10.2026. После восстановления nativeText.extension пользователь подтвердил отображение сносок в dynamic и попросил заменить пустые исходные строки одной раскрываемой строкой на группу соседних определений. Это не отчёт о полном наборе тестов предыдущего кандидата.

Группируются только распознанные definitionSources, включая неиспользованные и дубликаты. Пробелы, tabs и переводы строк между соседними определениями входят в диапазон группы. Обычный текст/заголовок/иной непустой блок разделяет группы. Внешние пустые строки не поглощаются. Inline ^[body] не является определением и в эти группы не входит.

В dynamic группа заменяется одной кнопкой-строкой «Исходники сносок · N». Клик ставит курсор в начало реального исходного диапазона. Любой курсор или пересекающееся выделение удерживает всю группу раскрытой; после ухода всех диапазонов она сворачивается. Стрелки перехватываются только при пересечении скрытой группы, без выделения/мультикурсора; используются CM moveVertically/moveByChar. Вертикальный вход сохраняет колонку в пределах первой/последней исходной строки. Весь остальной keyboard pipeline остаётся штатным. Диапазон не добавляется в atomicRanges.

Старые индивидуальные пустые replacements определений удалены из footnote_dynamic.js; новые групповые replacements обслуживает отдельный StateField. Кнопка «Исходник» в отрисованном списке сохраняет свой точный bodyFrom и тем самым раскрывает всю группу. Footer, нумерация ссылок, backlinks и подсветка не переписаны. Для группы gutter показывает реальный номер первой исходной строки; footer сохраняет пустой маркер.

Клик проверяет текущие context scope, диапазон и canNavigate; закрытые heading sections не получают дополнительного виджета поверх fold. Read-only разрешает только просмотр/выделение: изменений doc новые обработчики не отправляют. Нет текстовых изменений при сворачивании и раскрытии, сохранение и история текста остаются прежними. Source/reading не получают новую строку группы. editor.js не меняется: локальное восстановление nativeText.extension не перезаписывается этим коммитом.

Контракт: .wv-footnote-source-group, data-wv-footnote-group и data-wv-footnote-scope; window.__WV_FOOTNOTE_GROUPS_TEST='footnote-groups-20f'.

Проверки ассистента: 8 модельных node:test прошли, Node --check адаптера и изменённого dynamic прошёл. Настоящий CM/DOM, наложение decorations, геометрия одной строки, wrapped/bidi keyboard, Firefox/IIS и полный npm test:all/build не запускались. Требуется браузерная проверка, это кандидат.

```powershell

npm run build
```
