## Первый полный пользовательский прогон
Пользователь предоставил npm run test:all: 52 файла, 326 тестов, 325 pass, 1 fail, без skipped/cancelled/todo. Единственный провал — real fixture suite passes and real assertion failure propagates в test_all.test.mjs: ожидался код 1 от намеренно падающего временного теста, получен 0. Остальные тесты этого прогона прошли. Полный набор до исправления не считается зелёным.

Причина воспроизведена у ассистента под Node v20.20.1: самотест уже исполнялся в worker node:test, вложенный процесс наследовал NODE_TEST_CONTEXT=child-v8. Node пропускал вложенный запуск с предупреждением «node:test run() is being called recursively within a test file. skipping running files.» и возвращал 0. Предыдущие изолированные проверки вне worker этого случая не охватили. Это не доказанная Windows-специфичная ошибка и не дефект Markdown.

run_all_tests теперь передаёт копию окружения без NODE_TEST_CONTEXT, учитывая регистр имени ключа. Родительский process.env и остальные переменные (включая PATH/NODE_OPTIONS) не изменяются. Остальные проверки/передача кодов ошибок сохранены. Самотест по-прежнему требует 1 от реального провала; дополнительно проверяет, что fixture действительно исполнился, а не дал ложный успех после пропуска. TAP принудительно задаётся только захваченным временным fixture-процессам, не всему пользовательскому запуску.

У ассистента выполнены все 5 исправленных самотестов в изолированной копии runner+test_all под настоящим node --test, включая реальные pass/fail fixture-процессы: 5 pass, 0 fail. Полный WebVault, пользовательский Windows/Node и browser здесь не запускались. После pull повторить npm run test:all. npm install/build, перенос bundle и проверка сайта для этого фикса не нужны.
