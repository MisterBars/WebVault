# Ссылки в ячейках — кандидат table-links-18b, 24.10.2026

Дополнение к tables.md/next_steps.md, прежние задачи не заменяются. Пользователь принял table-cells-18a: редактирование ячеек и создание таблиц проверены. Вывод полного npm test/build не предоставлен.

Выравнивание: --- — default темы/renderer, :--- — явно слева, :---: — центр, ---: — справа. Новая таблица сохраняет ---; существующая матрица сохраняет :---: без массовой перезаписи. Изменение настроек alignment через UI в этот комплект не входит.

В редактор ячейки подключён принятый native picker свойств: [[, имя/путь, мышь/стрелки/Enter/Tab/Escape, выделение подписи после выбора, Ctrl+Space для обновления. При открытом меню клавиши выбирают ссылку раньше навигации таблицы. Выбор заполняет только черновик; Enter/Ctrl+S/обычное подтверждение сохраняют его. Popup в body исключён из наружного pointerdown commit, иначе выбор мышью терялся бы. При закрытии/подтверждении контроллер уничтожается.

Редактор показывает wiki с обычным | между адресом и подписью: из source удаляется только структурное экранирование pipe. При commit прежний tableCellChange экранирует pipe и сохраняет количество столбцов/alignment; один шаг Undo, прежнее автосохранение. Другие backslash-последовательности не декодируются. Prefix/suffix текста ячейки сохраняются.

Каталог по умолчанию теперь общий на объект WebVaultCore через WeakMap: тело, свойства и таблицы используют один кэш и invalidation. createLinkCatalog с явно переданными лимитами остаётся отдельным. Лимиты, auth/сессия, смена владельца и запрет stale response сохранены. Provider ячейки проверяет doc/user/path/canWrite и snapshot. Новых серверных запросов к текстам заметок/графу нет.

Property picker получил необязательные enabled/validateValue/menuLabel, прежние defaults свойств сохранены. Для ячейки code/скрытые комментарии выключают меню; при проверке завершённости ссылок их текст маскируется, чтобы буквальный [[ в коде не мешал сохранить ячейку. Это не обещание полной поддержки всех Markdown-конструкций.
