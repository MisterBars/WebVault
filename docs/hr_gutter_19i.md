## Точечное изменение
Для существующего BlockWidget с первым parser token hr SourceBlockNumber получает пустую строку вместо номера. Это явный пустой GutterMarker, не возврат null с возможным штатным fallback. Для синтетической панели без исходных строк прежний null сохраняется. Остальные виджеты получают прежний номер. Определение по token type, не по текстовому regexp: Setext, код с --- и вложенный hr не теряют номер контейнера.

Пока разделитель отрисован в dynamic, цифра не показывается; при раскрытии строки работает штатная нумерация исходника. В source BlockWidget отсутствует и номера не скрываются. Reading без новой нумерации. Реальная исходная строка, source maps, соседние пустые строки и следующие номера не изменяются. Высота HR/CSS/gutter transform/selection/folding не меняются.

Если после скрытия этой цифры продолжают накладываться номера соседних реальных строк, нужна отдельная диагностика высот/позиционирования, а не дальнейшее скрытие номеров. Комплект не объявляет геометрию доказанно исправленной без браузера.
