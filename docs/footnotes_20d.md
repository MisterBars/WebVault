## Этот комплект: чтение
Сноска принадлежит ближайшему заголовку, содержащему первое упоминание. Она показывается в конце его полного раздела, перед следующим заголовком того же/более высокого уровня. Родительский раздел включает вложенные; при общей границе сначала выводятся сноски дочернего раздела, затем родительского. Преамбула до первого заголовка имеет свой список перед ним; без заголовков список остаётся в конце документа.

Глобальная нумерация не перезапускается. Повторная именованная сноска в другом разделе не дублируется: один номер и одно тело в разделе первого упоминания, backlinks ко всем её упоминаниям. Это выбранная явная политика первого этапа. Если нужен отдельный экземпляр тела в каждом разделе, согласовать отдельно, не менять IDs/ссылки молча.

В закрытом разделе его список не отображается; при ссылке на неотображаемую цель показывается статус, без автоматического раскрытия. Диагностические details неиспользованных/повторных definitions остаются общими внизу. Низкоуровневый renderFootnoteDocument без sections сохраняет глобальный список; в приложении размещение выполняет renderHeadingReading.

Переход центрирует цель, ставит view-only focus и на 1800ms выделяет ближайший paragraph/li/heading через .wv-footnote-target. Следующий переход очищает старую подсветку; старый callback не очищает новую. Render roots независимы. CSS использует text-highlight-bg/background-modifier-hover, interactive-accent, radius-s, без анимации/изменения высот. Никаких selection/changes документа, URL hash или новых внешних переходов. Метка window.__WV_FOOTNOTES_SECTIONS_TEST='footnotes-sections-20d' после входа в чтение.
